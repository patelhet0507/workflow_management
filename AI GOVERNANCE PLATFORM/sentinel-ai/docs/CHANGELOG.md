# Changelog

## 0.1.0 (2026-07-17)

### Initial Release — Dashboard MVP

- **Dashboard** — Overview page with stats cards, system health, and charts
- **Stats Cards** — Running agents, failed executions, API requests, token usage, latency, cost
- **System Health** — Overall status, success rate, error rate, response time, uptime
- **Charts** — Agent executions (line), token consumption (area), cost per day (bar), success rate (pie)
- **Activity Table** — Real-time event stream with status indicators
- **Agent Cards** — 8 agent overview cards with expandable details
- **Alerts Panel** — Critical, warning, and info alert display
- **Infrastructure Widget** — CPU, RAM, GPU, API, database, queue health
- **Theme** — Dark mode enterprise theme with Geist font
- **Layout** — Collapsible sidebar, top nav with search, notifications, profile
