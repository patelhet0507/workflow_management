# Sentinel AI

**Enterprise Runtime Governance Platform for AI Agents**

Sentinel AI is the runtime operating layer that sits between AI Agents and the outside world. It makes AI agents observable, secure, governed, auditable, and cost-efficient.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the dashboard.
